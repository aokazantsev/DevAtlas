# DevAtlas

Образовательное приложение для разработчиков: темы с деревом подтем, страницы со схемами и отметка
«Просмотрено». Тему добавляют ссылкой (папка Яндекс.Диска, GitHub, zip), дальше приложение работает
без сети.

Скачать — APK со страницы [выпусков](https://github.com/aokazantsev/DevAtlas/releases/latest), что изменилось — в
[CHANGELOG](CHANGELOG.md). В приложении: дизайн-система на Material 3 Expressive с цветами из обоев, формат темы с
проверкой, тема-пример и управление темами: онбординг, добавление по ссылке, установка, обновление, смена и удаление;
содержание темы с прогрессом,
страницы со схемами и отметкой «Просмотрено», подсветка кода на 25 языках с кнопкой «Копировать», закладки и
продолжение с последней точки, ссылки на сайты во встроенном браузере и PDF в «Загрузках», «О приложении», проверка
и установка обновлений, отчёты о сбоях и статистика использования по согласию.

## Платформы

Kotlin Multiplatform + Compose Multiplatform. Собирается только Android (от Android 10).
Логика, данные, навигация, интерфейс и дизайн-система лежат в общем коде, но iOS не собирается
и не проверяется: целей iOS в проекте нет.

## Сборка

Нужны JDK 21 и Android SDK (путь — в `local.properties` или `ANDROID_HOME`).

```
./gradlew :app:assembleNoSslDebug
./gradlew detekt
./gradlew :detekt-rules:test :designsystem:testAndroidHostTest :shared:testAndroidHostTest :themeformat:jvmTest :tools:themecheck:test
./gradlew :app:connectedSslDebugAndroidTest
```

Последняя команда — e2e-тесты на подключённом телефоне или эмуляторе.

Сборки делятся по доверию к сертификатам: `ssl` доверяет только системным центрам сертификации, как релиз;
`noSsl` — ещё и установленным пользователем, чтобы отладочный прокси (Charles, AgentProxy) видел HTTPS приложения.
`noSsl` бывает только отладочной, релиз — `assembleSslRelease`, e2e-тесты идут на `sslDebug`.
APK отладочной сборки — `app/build/outputs/apk/noSsl/debug/`. В отладочной сборке в настройках есть
каталог компонентов дизайн-системы в светлой и тёмной теме.

Релиз подписывается ключом, которого нет в репозитории. Путь к файлу свойств подписи задаёт переменная окружения
`DEVATLAS_SIGNING` или строка `devatlas.signing=<путь>` в `local.properties` (прямые слеши). В файле — `storeFile`
(путь к хранилищу, относительный — от папки файла), `storePassword`, `keyAlias`, `keyPassword`. Путь не задан —
релиз собирается без подписи (так собирает CI); задан, но файла или ключей нет — сборка падает. Перед публикацией
APK — `apksigner verify --print-certs`: сертификат должен совпасть с прошлыми выпусками, иначе обновление поверх
не встанет.

## Устройство

| Модуль | Что внутри |
|---|---|
| `:app` | точка входа Android: `Application`, `Activity`, системный сплеш, иконка |
| `:shared` | общий код приложения: граф DI, навигация, экраны, настройки, база |
| `:designsystem` | тема Material 3 Expressive, иконки и компоненты; единственное место, где используется Material3 |
| `:themeformat` | формат темы: манифест, разбор страниц и схем, проверка, безопасная распаковка архива, подсветка кода |
| `:tools:themecheck` | проверка и упаковка темы из командной строки |
| `:detekt-rules` | свои правила detekt: цвета, отступы и Material3 только в дизайн-системе |

Библиотеки: Compose Multiplatform, Navigation Compose, Metro (DI), Room, DataStore, okio, Ktor,
kotlinx-serialization, AndroidSVG (схемы рисуются вектором, на Android), WorkManager (фоновая отправка статистики, на Android). Версии — `gradle/libs.versions.toml`.
Подсветка кода — свой лексер на правилах в общем коде (`:themeformat`, пакет `code`), без WebView и JavaScript:
готовые KMP-библиотеки не покрывают весь список языков. Цвета токенов — роли схемы Material 3, поэтому код
перекрашивается с темой и цветами обоев.

## Как добавить тему в приложение

Тема — это ссылка, отдельного каталога нет. Приложение определяет вид источника по адресу и скачивает его как zip:

| Источник | Адрес |
|---|---|
| Папка или файл `.zip` на Яндекс.Диске | публичная ссылка `disk.yandex.ru/d/…` или `/i/…` |
| Репозиторий или папка GitHub | `github.com/владелец/репозиторий` или `…/tree/ветка/папка` (ветка без `/` в имени) |
| Файл `.zip` на Google Диске | ссылка на файл `drive.google.com/file/d/…` с доступом «Все, у кого есть ссылка» |
| Любой сайт | прямая ссылка `https://…/тема.zip` |

Адрес `http://`, папка Google Диска, Dropbox и обычные папки на сайтах не принимаются: приложение объясняет, почему. Тема
сначала скачивается и проверяется тем же валидатором, что и `themecheck`, потом показывается превью (название,
описание, число страниц, размер) и только после «Установить» ставится: временная папка, проверка, переименование.
Обновление — только вручную, из «Настройки → Список тем»: приложение сверяет `ETag` и хеш содержимого темы и показывает,
сколько страниц добавится, удалится и изменится.

## Закладки и продолжение

Закладку ставит значок в шапке страницы, раздела или содержания: она запоминает экран, место прокрутки и название
(по умолчанию — заголовок экрана). Список — значок «Закладки» в шапке содержания: нажатие открывает экран, значок
карандаша переименовывает или удаляет, удержание и перетаскивание меняет порядок. Место прокрутки хранится как
номер блока страницы или строки содержания, а не в пикселях: оно переживает смену шрифта и обновление темы.

Настройка «Продолжать с последней точки» (включена по умолчанию) при запуске открывает последний экран с тем же
местом прокрутки; «Назад» ведёт вверх по дереву темы. Закладки и последняя точка хранятся рядом с отметками
«Просмотрено» по `id` темы: «Сбросить прогресс» стирает их вместе, удаление темы без сброса оставляет, после
обновления темы закладки исчезнувших страниц и разделов удаляются.

## Ссылки и файлы

Ссылка `page:` открывает страницу темы поверх текущей: «Назад» возвращает туда, где нажали ссылку. Сайт
(`https://`) открывается во встроенном браузере: в шапке — заголовок страницы и под ним адрес сайта (длинный адрес
сокращается с начала, конец домена виден всегда), «Копировать ссылку» и
«Открыть в браузере», «Назад» идёт по истории сайта, потом закрывает экран. Если встроенный браузер упал (странице не
хватило памяти), вместо страницы — «Повторить» и «Открыть в браузере». Почта и телефон уходят приложениям телефона.
Удержание пальца на ссылке страницы темы открывает «Копировать ссылку», у ссылки на `.pdf` — ещё «Скачать заново»;
владельцу TalkBack «Копировать ссылку» доступна среди действий ссылки без удержания. На Android 10–12 после копирования
приложение само показывает «Скопировано», на 13 и новее — системное подтверждение. Окно «Копировать ссылку» переживает
поворот экрана.

PDF (ссылка на `.pdf` или файл, который сайт во встроенном браузере отдал как PDF) приложение по нажатию скачивает
само в `Загрузки/DevAtlas` через MediaStore, без разрешений, и открывает программой для PDF. Нажатие — касание пальцем,
двойное касание TalkBack или Enter на клавиатуре; прокрутка и удержание нажатием не считаются. Одно нажатие — один
PDF, даже если сервер отвечает долго (до минуты); скрипт сайта без нажатия PDF не скачает. Имя — из атрибута `download`,
иначе из ответа сервера, имени файла в адресе, заголовка страницы или домена с датой; совпадение имён — ` (1)`.
Пока файл качается, он скрыт от других программ, отмена его удаляет. Шторка «Скачиваю PDF» не закрывается свайпом,
касанием мимо или «Назад»: остановить загрузку можно только кнопкой «Отмена». Если загрузка закончилась, когда
приложение было в фоне (Android не даёт открыть программу из фона), при возврате появится «PDF скачан» с кнопкой
«Открыть». Приложение помнит, какой адрес в какой файл
скачан: повторное нажатие на ссылку `.pdf` открывает файл без сети, а если файла уже нет — качает заново. PDF, который
нашёлся на сайте, без сети открывается из «Скачанных файлов». Предел — 100 МБ.
Список — «Настройки → Скачанные файлы»: открыть, поделиться, удалить файл или все сразу.

## Обновление и данные

Новую версию приложение ищет в GitHub Releases этого репозитория: раз в сутки при запуске (настройка «Проверять
обновления», включена по умолчанию) и по кнопке «Проверить обновление» в «О приложении». «Что нового» — описания
выпусков новее установленного; без сети показывается список с прошлой проверки. «Обновить» скачивает APK из выпуска и
ставит его системным установщиком, только если контрольная сумма sha256 совпала с той, что GitHub показывает у файла;
в первый раз Android попросит разрешить DevAtlas устанавливать приложения.

На сайт автора (`aokazantsev.ru`) приложение отправляет данные только по согласию, его дают при первом запуске и меняют
в «Настройки → Данные»:

- отчёт о сбое (по умолчанию выключен): версия приложения и Android, модель телефона, текст ошибки и хвост журнала
  приложения; уходит один раз при следующем запуске;
- статистика (по умолчанию включена): случайный номер установки, сколько раз за сутки использовались функции и текущие
  настройки; уходит при запуске и раз в 12 часов в фоне (WorkManager). Выключение стирает накопленные счётчики.

Что именно уходит — [политика](https://aokazantsev.ru/privacy#devatlas), раздел 8.

## Как сделать тему

Формат темы описан в [docs/theme-format.md](docs/theme-format.md), пример — папка
[sample-theme](sample-theme). Проверить свою тему и собрать архив:

```
./gradlew :tools:themecheck:run --args="путь/к/теме --zip тема.zip"
```

## Ограничения

- Схемы разбираются в фоне (пока схема не готова, на её месте — индикатор загрузки), а рисуются вектором на главном
  потоке. Приложение отклоняет схему, у которой больше 20 000 элементов
  вместе с раскрытыми ссылками `<use>`, ссылки зациклены или вложены глубже 32 уровней, но не считает цену узоров
  (`<pattern>`) и маркеров линий: тема, специально собранная так, чтобы рисоваться очень долго, может подвесить
  экран своей страницы. Такую тему стоит удалить.
- Подсветка кода — лексическая, без разбора синтаксиса: регулярные выражения в JavaScript отличаются от деления по
  предыдущему символу, вставки в строках (`${…}`) не подсвечиваются внутри, в HTML подсвечиваются вложенные
  `<script>` и `<style>`, а в Markdown — только разметка, без кода внутри блоков. Блок длиннее 20 000 символов
  показывается моноширинным текстом без подсветки (`CodeHighlighter.MAX_CODE_LENGTH`), проверка темы предупреждает.
- Место закладки и последней точки точно до блока: внутри длинного блока кода или таблицы экран откроется на его
  начале.
  Перетаскивание закладок не прокручивает список у края экрана: в длинном списке закладку переносят в несколько
  приёмов или действиями «Переместить выше/ниже» в TalkBack.
- После переустановки приложения старые файлы в `Загрузки/DevAtlas` для него чужие: первое нажатие на ссылку качает
  PDF заново, с номером в имени. Скачивание идёт без cookie встроенного браузера: PDF, который сайт отдаёт только
  после входа, не скачается. Остальные файлы (не PDF) встроенный браузер не скачивает: ссылка темы на такой файл уходит в
  браузер телефона, а на сайте — «Открыть в браузере» в шапке. Сайт по `http://` открывается в браузере телефона.
