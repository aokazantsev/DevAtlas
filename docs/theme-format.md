# Формат темы DevAtlas

Источник истины формата. Страница «Как сделать тему» на сайте (`aokazantsev.ru/pets/devatlas/themes/`)
собирается из этого файла, правятся вместе. Якоря разделов (`#manifest`, `#links`…) постоянные: на них
ссылаются сообщения проверки в приложении и в `themecheck`.

Версия формата — **1** (`formatVersion` в манифесте).

<a id="folder"></a>
## Папка темы

Тема — папка с файлом `manifest.json` в корне, страницами `.html` и схемами `.svg`. Вложенные папки —
как удобно автору.

```text
manifest.json
pages/
  welcome.html
  basics/intro.html
diagrams/
  flow.svg
```

- Файлы `.md` и `.txt` (например, README) разрешены, приложение их не читает.
- Скрытые файлы и папки (имя с точки, `.git`) и `__MACOSX` пропускаются.
- Любые другие файлы — ошибка: картинки PNG и JPG не поддерживаются, схемы — только SVG.
- Файл `.html` или `.svg`, на который нет ссылки ни из манифеста, ни со страниц, — предупреждение.
- Имя файла и папки не может оканчиваться пробелом или точкой: Windows молча отрезает их, и такая тема не
  соберётся на другом компьютере.
- Пределы: файлов в теме — до 2000, один файл — до 1 МБ, вся тема — до 100 МБ, вложенность — до 8 папок,
  путь от корня темы — до 200 символов. Те же пределы проверяются у архива, см. [Архив](#archive).
- Замечаний на файл показывается до 100, остальные — одной строкой «и ещё N». После 1000 замечаний на тему
  проверка останавливается: исправьте найденное и запустите её снова.

<a id="encoding"></a>
## Кодировка

Все текстовые файлы — в UTF-8 (с BOM или без). Файл в другой кодировке — ошибка.

<a id="manifest"></a>
## manifest.json

```json
{
  "formatVersion": 1,
  "id": "android-basics",
  "title": "Основы Android",
  "description": "Короткое описание для превью перед установкой.",
  "tree": [
    { "id": "welcome", "title": "Добро пожаловать", "file": "pages/welcome.html" },
    {
      "id": "basics",
      "title": "Основы",
      "children": [
        { "id": "intro", "title": "Введение", "file": "pages/basics/intro.html" }
      ]
    }
  ]
}
```

| Поле | Обязательное | Что это |
|---|---|---|
| `formatVersion` | да | целое число — версия формата, сейчас `1` (не в кавычках, не `1.0`) |
| `id` | да | постоянный id темы; по нему приложение узнаёт тему при обновлении и хранит прогресс |
| `title` | да | название темы |
| `description` | нет | описание для превью |
| `tree` | да | непустой список узлов верхнего уровня |

Неизвестные поля — предупреждение, приложение их пропускает.

<a id="ids"></a>
## id

`id` темы и каждого узла — строчные латинские буквы, цифры и дефисы между ними: `kotlin-basics`,
`intro-2`. До 64 символов. `id` узлов уникальны в пределах темы.

**Не меняйте `id` после публикации:** прогресс «Просмотрено» хранится по паре «id темы + id страницы».
Страница с новым `id` для приложения — новая страница, отметка старой пропадёт. Меняйте `title` и
`file` сколько угодно.

<a id="tree"></a>
## Дерево

Узел — либо **страница** (поле `file`), либо **раздел** (поле `children`), ровно одно из двух.

- `file` — путь к `.html` от корня темы через `/`, без `..` и без `/` в начале.
- `children` — непустой список узлов.
- Глубина дерева — до 6 уровней.
- Вводный текст раздела — отдельная страница первым узлом в `children`.
- Один файл на две страницы — предупреждение.

<a id="html"></a>
## Страницы: HTML

Страница — фрагмент HTML: только содержимое, без `<html>`, `<head>` и `<body>`; такие теги — ошибка. Приложение рисует страницу само, в шрифтах и цветах приложения; скрипты и стили не
выполняются.

| Теги | Что это |
|---|---|
| `h1`–`h6` | заголовки |
| `p`, `br`, `hr` | абзац, перенос строки, разделитель |
| `b`, `strong`, `i`, `em`, `code` | жирный, курсив, код в строке |
| `ul`, `ol`, `li` | списки, в том числе вложенные |
| `pre` + `code class="language-…"` | блок кода, язык — в классе, см. [Код](#code) |
| `blockquote` | цитата |
| `table`, `thead`, `tbody`, `tfoot`, `tr`, `th`, `td` | таблица |
| `a` | ссылка, см. [Ссылки](#links) |
| `img`, `figure`, `figcaption` | схема с подписью, см. [Схемы](#images) |

- Неизвестный тег (`div`, `span`, `section`…) — предупреждение, его текст показывается как обычный.
- `script`, `style`, `iframe`, `svg` внутри страницы и подобные пропускаются вместе с содержимым,
  предупреждение.
- Разрешённые атрибуты: у любого тега `id`, `class`, `title`, `lang`, `dir`; у `a` — `href`, `download`,
  `target`, `rel`; у `img` — `src`, `alt`, `width`, `height`; у `ol` — `start`. Приложение читает только
  `href`, `download`, `src`, `alt` и `class` у `code`, остальные пропускает молча. `style`, `on…` и прочие —
  предупреждение.
- Незакрытый тег или лишний закрывающий — предупреждение. Оборванный тег (`<b` без `>`) — ошибка.
- Ссылка внутри ссылки (`<a>` в `<a>`) — предупреждение: внутренняя ссылка не работает, её текст становится частью внешней.
- Спецсимволы — как в HTML: `&lt;`, `&amp;`, `&nbsp;`, `&laquo;`, `&mdash;`, `&#8594;`. Именованных —
  распространённые (кавычки, тире, стрелки, знаки сравнения, `&copy;`, `&deg;` и подобные); незнакомое имя
  показывается как есть, с предупреждением: такой символ пишите числом (`&#8734;`).
- В коде тегов нет: `<` и `&` пишутся как `&lt;` и `&amp;`. Тег внутри блока кода (`pre`) — ошибка, внутри
  `code` в строке допустимы только `b`, `strong`, `i`, `em`.
- Незакрытый `script` или `style` — ошибка: если это текст, пишите `&lt;style&gt;`.

<a id="code"></a>
## Код

Блок кода — `pre` с `code` внутри, язык — классом `language-…`:

```html
<pre><code class="language-kotlin">fun greet(name: String) = "Привет, $name"
</code></pre>
```

Приложение подсвечивает код цветами темы (они меняются вместе со светлой и тёмной темой и цветами обоев),
пишет над блоком название языка и кнопку «Копировать». Пробелы и переносы — как у автора, длинные строки не
переносятся: блок прокручивается вбок. Номеров строк нет.

| Язык | Класс | Короткие имена |
|---|---|---|
| Kotlin | `language-kotlin` | `kt`, `kts` |
| Java | `language-java` | |
| Swift | `language-swift` | |
| Objective-C | `language-objectivec` | `objc`, `objective-c` |
| Dart | `language-dart` | |
| JavaScript | `language-javascript` | `js` |
| TypeScript | `language-typescript` | `ts` |
| Python | `language-python` | `py` |
| Go | `language-go` | `golang` |
| Rust | `language-rust` | `rs` |
| C | `language-c` | |
| C++ | `language-cpp` | `c++` |
| C# | `language-csharp` | `cs` |
| PHP | `language-php` | |
| Ruby | `language-ruby` | `rb` |
| Shell | `language-shell` | `sh`, `bash` |
| SQL | `language-sql` | |
| Groovy | `language-groovy` | `gradle` |
| JSON | `language-json` | |
| YAML | `language-yaml` | `yml` |
| XML | `language-xml` | |
| HTML | `language-html` | |
| CSS | `language-css` | |
| Markdown | `language-markdown` | `md` |
| Diff | `language-diff` | `patch` |
| простой текст | `language-text` | `plaintext`, `txt` |

- Регистр в имени языка не важен: `language-Kotlin` = `language-kotlin`.
- Без языка или с незнакомым языком блок показывается моноширинным текстом без подсветки, предупреждение.
  Для текста без подсветки (дерево папок, вывод программы) пишите `language-text` — без предупреждения.
- JSON показывается как написан, без переформатирования. Невалидный JSON в `language-json` — предупреждение
  с номером строки и столбца внутри блока.
- Блок длиннее 20 000 символов показывается без подсветки, предупреждение: разбейте его на части.
- Код в строке (`<code>` внутри абзаца) не подсвечивается.

<a id="links"></a>
## Ссылки

| Адрес | Куда ведёт |
|---|---|
| `page:<id>` | страница этой же темы, `id` из манифеста |
| `https://…` | сайт, открывается внутри приложения с кнопкой «Открыть в браузере» |
| `mailto:…`, `tel:…` | почта и телефон, открываются приложениями телефона |

- `page:` на несуществующую страницу или на раздел — ошибка.
- `http://` — ошибка: замените на `https://`.
- Относительные пути (`other.html`), якоря (`#part`) и прочие схемы — ошибка.
- Ссылка без `href` — предупреждение, показывается как текст.

<a id="pdf"></a>
## PDF

Ссылку `https://…` на файл `.pdf` приложение скачивает в `Загрузки/DevAtlas` и открывает. Имя файла
задаёт атрибут `download`:

```html
<a href="https://example.com/guide.pdf" download="guide.pdf">Руководство (PDF)</a>
```

- `download` — имя с окончанием `.pdf`, без папок и символов `\ / : * ? " < > |`, до 120 символов;
  иначе ошибка.
- Без `download` — предупреждение: имя возьмётся из ответа сервера.
- `download` у ссылки не на PDF — предупреждение, атрибут пропускается.

<a id="images"></a>
## Схемы на странице

Схема подключается тегом `img`, путь — относительно файла страницы:

```html
<figure>
  <img src="../diagrams/flow.svg" alt="Путь запроса от экрана до сервера">
  <figcaption>Подпись под схемой.</figcaption>
</figure>
```

- Только файлы `.svg` из папки темы; адреса `https://`, `data:` и пути за пределы темы — ошибка.
- Файла нет — ошибка.
- Без `alt` — предупреждение: описание читает экранный диктор.
- `img` внутри абзаца разбивает абзац на две части; внутри `b`, `a` и подобных — предупреждение,
  схема пропускается.

<a id="svg"></a>
## SVG

- Корректный XML с одним корневым `<svg>`; иначе ошибка. Значения атрибутов — в кавычках, атрибут не
  повторяется. Из именованных спецсимволов XML знает только `&amp;`, `&lt;`, `&gt;`, `&quot;`, `&apos;`,
  остальные — числом (`&#160;` вместо `&nbsp;`). Символ `<` в тексте и в значениях — только `&lt;`.
  `<!DOCTYPE` и `<!ENTITY` — ошибка.
- Нужен `viewBox`, иначе схема не подстроится под ширину экрана (предупреждение).
- Запрещены: `<script>`, `<foreignObject>`, `<style>`, `<image>`, `<iframe>`, `<audio>`, `<video>`, атрибуты `on…` и анимация — `<set>`, `<animate>`,
  `<animateTransform>`, `<animateMotion>`, `<animateColor>`, `<discard>`: схема статична. Ссылки (`href`, `xlink:href`, `url(…)`) — только на
  свои элементы: `#id`.
- Схема не должна быть слишком сложной: до 20 000 элементов с учётом копий через `<use>`, `<use>` не ссылается
  на себя по кругу, цепочка `<use>` → `<use>` — не длиннее 32. Иначе ошибка: такую схему телефон не нарисует.

<a id="colors"></a>
## Цвета в SVG

Цвет задаётся не числом, а ролью цвета приложения — тогда схема перекрашивается вместе с темой
оформления и цветами обоев. В атрибутах `fill`, `stroke`, `stop-color`, `flood-color`, `lighting-color`,
`color` и в тех же свойствах внутри `style` допустимы:

- `var(--<роль>)` — роль из списка ниже;
- `currentColor` — основной цвет текста (`on-surface`);
- `none`, `transparent`, `inherit`;
- `url(#id)` — свой градиент или узор (только в `fill` и `stroke`).

`#ff0000`, `red`, `rgb(…)` — ошибка. Неизвестная роль — ошибка.

Задайте `fill="currentColor"` у корня `<svg>`: иначе фигуры без своего цвета станут чёрными
(предупреждение).

Роли — все роли схемы цветов Material 3:

| Группа | Роли |
|---|---|
| Акцент | `primary`, `on-primary`, `primary-container`, `on-primary-container`, `inverse-primary` |
| Второй план | `secondary`, `on-secondary`, `secondary-container`, `on-secondary-container` |
| Третий план | `tertiary`, `on-tertiary`, `tertiary-container`, `on-tertiary-container` |
| Ошибка | `error`, `on-error`, `error-container`, `on-error-container` |
| Поверхности | `background`, `on-background`, `surface`, `on-surface`, `surface-variant`, `on-surface-variant`, `surface-tint`, `inverse-surface`, `inverse-on-surface`, `surface-bright`, `surface-dim`, `surface-container-lowest`, `surface-container-low`, `surface-container`, `surface-container-high`, `surface-container-highest` |
| Линии | `outline`, `outline-variant`, `scrim` |
| Фиксированные | `primary-fixed`, `primary-fixed-dim`, `on-primary-fixed`, `on-primary-fixed-variant`, `secondary-fixed`, `secondary-fixed-dim`, `on-secondary-fixed`, `on-secondary-fixed-variant`, `tertiary-fixed`, `tertiary-fixed-dim`, `on-tertiary-fixed`, `on-tertiary-fixed-variant` |

Обычно хватает `primary-container`, `secondary-container`, `tertiary-container` для блоков, `on-…` для
текста на них, `on-surface` и `outline` для линий.

<a id="archive"></a>
## Архив

Тему можно отдать zip-архивом. Корень темы в архиве — где лежит `manifest.json`: в корне архива или в
единственной папке внутри него (так выглядит архив ветки GitHub). Для папки GitHub корень — указанная
подпапка. Файлы вне корня темы не распаковываются, и правила имён и путей к ним не применяются; размер
архива, число записей, ZIP64 и кодировка имён проверяются у всего архива — для папки GitHub это архив всей ветки.

Архив отклоняется целиком, если:

- среди файлов темы есть пути с `..`, абсолютные пути, обратные слеши, пустые сегменты пути (`//`), символы
  `: * ? " < > |` в именах, имена, оканчивающиеся пробелом или точкой, символические ссылки или два файла с
  именами, различающимися только регистром;
- он защищён паролем, сжат не обычным методом zip, в формате ZIP64 или повреждён;
- имена файлов не в UTF-8;
- больше 50 МБ, больше 2000 файлов темы (папки, скрытые файлы и `__MACOSX` не считаются), больше 20 000 записей в
  каталоге архива, вложенность больше 8 папок, путь длиннее 200 символов, файл больше 1 МБ или тема после
  распаковки больше 100 МБ.

## Проверка и упаковка: themecheck

```text
./gradlew :tools:themecheck:run --args="путь/к/теме"
./gradlew :tools:themecheck:run --args="путь/к/теме --zip тема.zip"
./gradlew :tools:themecheck:run --args="тема.zip --strict"
```

`--zip` собирает архив, только если ошибок нет; файл архива нельзя класть внутрь папки темы. `--strict` считает предупреждения ошибками. Код выхода:
`0` — ошибок нет, `1` — есть ошибки, `2` — неверные аргументы.
