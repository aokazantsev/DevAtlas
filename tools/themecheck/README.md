# themecheck

Проверка темы DevAtlas тем же валидатором, что и в приложении, и упаковка темы в zip.

```
./gradlew :tools:themecheck:run --args="путь/к/теме"
./gradlew :tools:themecheck:run --args="путь/к/теме --zip тема.zip"
./gradlew :tools:themecheck:run --args="тема.zip --strict"
```

- `--zip <файл>` — собрать архив, если ошибок нет. Порядок файлов и время в архиве постоянные: одна и та же
  тема даёт один и тот же архив.
- `--strict` — считать предупреждения ошибками.
- Код выхода: `0` — ошибок нет, `1` — есть ошибки, `2` — неверные аргументы.

Каждое замечание — файл, строка и столбец, текст и ссылка на раздел «Как сделать тему». Формат —
[docs/theme-format.md](../../docs/theme-format.md).
