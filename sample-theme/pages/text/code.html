Код

Блок кода — pre с code внутри. Язык указывается классом language-…: приложение покажет его в подписи блока и подсветит код цветами темы. Кнопка «Копировать» над блоком кладёт код в буфер обмена.

@Composable
fun Greeting(name: String) {
    Text(text = "Привет, $name!")
}

Пробелы и переносы внутри блока сохраняются как есть, длинные строки не переносятся — блок прокручивается вбок. Простой текст без подсветки — класс language-text:

SELECT p.id, p.title, COUNT(v.id) AS views
FROM pages AS p
LEFT JOIN page_views AS v ON v.page_id = p.id
WHERE p.theme_id = 'devatlas-sample' AND v.viewed_at >= DATE '2026-10-01'
GROUP BY p.id, p.title
HAVING COUNT(v.id) > 0
ORDER BY views DESC
LIMIT 10;
