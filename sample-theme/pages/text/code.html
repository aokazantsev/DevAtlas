Код

Блок кода — pre с code внутри. Язык указывается классом language-…: приложение покажет его в подписи блока.

@Composable
fun Greeting(name: String) {
    Text(text = "Привет, $name!")
}

Пробелы и переносы внутри блока сохраняются как есть:

manifest.json
pages/
  welcome.html
diagrams/
  tree.svg

Символы < и & в коде пишутся как &lt; и &amp;: if (a < b && c) { }.
